# 01 — Hello, messages

This first example introduces values, variables, messages, string
interpolation, and visible output. There is no application framework hiding the
language.

Run it from the repository root:

```sh
./bin/run-example 01_hello_messages
```

Expected output:

```text
Hello, STreuth.
Messages can answer questions: true.
The answer is 42.
```

Try changing `subject`, then send `isInteger` to a different Number. Notice
that `println` is another message rather than special statement syntax.
