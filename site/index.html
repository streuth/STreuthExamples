First run

Open the guided tour workset

  1. In the file browser on the left, expand Tutorial.
  2. Right-click the 16_guided_ide_tour folder itself and choose Open Workset.
  3. Choose Run > Run Current File. Do not open and run Main.st by itself.

A workset tells the IDE which source files belong together. Opening it loads the tutorial's library and application sources and selects its runnable file.

A clean start

From download to running example

  1. Download one example ZIP below and expand it.
  2. Open it by right-clicking the expanded example folder in STreuthBrowser and choosing Open Workset.
  3. Copy it into your Workspace before changing it.

Official examples are managed reference material. Your Workspace copy is yours; future downloads do not merge over your edits.
